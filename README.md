# ระบบสมัครเรียนออนไลน์ (Online Student Registration System - UI Mockup)

## 1. ภาพรวมโครงการ

โปรเจกต์นี้เป็นระบบจำลองแบบฟอร์มลงทะเบียนและรับสมัครนักศึกษาวิทยาลัยหรือมหาวิทยาลัย พัฒนาด้วย **Pure HTML5 และ Pure CSS3** เน้น UX/UI ที่เรียบง่าย สะอาดตา และใช้งานสะดวก เหมาะสำหรับศึกษาการจัดโครงสร้างหน้าเว็บและการออกแบบขั้นตอนสมัครเรียน

โปรเจกต์นี้เป็น UI Mockup ไม่มี JavaScript ไม่มีระบบหลังบ้าน และไม่มีการบันทึกข้อมูลผู้สมัคร

## 2. โครงสร้างโฟลเดอร์

```text
project-root/
├── css/
│   └── app.css             # ไฟล์ CSS หลักควบคุมสไตล์ทั้งระบบ
├── img/
│   ├── logo_kmutnb-6.png   # โลโก้สถาบัน
│   └── Banner.png          # ภาพแบนเนอร์หน้าหลัก
├── index.html              # หน้าหลัก
├── date.html               # หน้ากำหนดการรับสมัคร
├── register.html           # หน้าลงทะเบียนบัญชีผู้สมัคร
├── student.html            # ขั้นตอนที่ 1: ข้อมูลส่วนตัวและเอกสาร
├── place.html              # ขั้นตอนที่ 2: ที่อยู่ปัจจุบัน
├── school.html             # ขั้นตอนที่ 3: ประวัติการศึกษา
├── parents.html            # ขั้นตอนที่ 4: ข้อมูลผู้ปกครอง
├── success.html            # หน้าแสดงผลสมัครเรียนสำเร็จ
└── README.md               # เอกสารอธิบายโครงการ
```

## 3. ลำดับการใช้งานและการเชื่อมโยงหน้า

ลำดับการสมัครหลักเริ่มจากหน้าหลัก ลงทะเบียนบัญชี แล้วกรอกข้อมูลสมัครตามขั้นตอนจนถึงหน้าสรุปผล

```text
index.html
  └── register.html
        └── student.html
              └── place.html
                    └── school.html
                          └── parents.html
                                └── success.html
```

| หน้า | การทำงานหลัก | การเชื่อมโยง |
|---|---|---|
| `index.html` | แสดงข้อมูลโครงการและทางเข้าสมัคร | ปุ่มสมัครไป `register.html`; กำหนดการไป `date.html` |
| `date.html` | แสดงกำหนดการตัวอย่าง | ปุ่มเริ่มสมัครไป `register.html`; กลับหน้าหลักไป `index.html` |
| `register.html` | กรอกข้อมูลบัญชีผู้สมัคร | ปุ่มลงทะเบียนไป `student.html`; ย้อนกลับไป `index.html` |
| `student.html` | กรอกข้อมูลส่วนตัวและเอกสาร | ปุ่มถัดไปไป `place.html`; ย้อนกลับไป `register.html` |
| `place.html` | กรอกที่อยู่ปัจจุบัน | ปุ่มถัดไปไป `school.html`; ย้อนกลับไป `student.html` |
| `school.html` | กรอกประวัติการศึกษาและเอกสาร | ปุ่มถัดไปไป `parents.html`; ย้อนกลับไป `place.html` |
| `parents.html` | กรอกข้อมูลผู้ปกครองและยืนยัน | ปุ่มยืนยันไป `success.html`; ย้อนกลับไป `school.html` |
| `success.html` | แสดงผลสมัครสำเร็จตัวอย่าง | ปุ่มกลับหน้าหลักไป `index.html` |

ลิงก์ไปมาระหว่างหน้าเป็นการนำทางของ UI Mockup เท่านั้น ข้อมูลที่กรอกจะไม่ถูกจัดเก็บหรือส่งต่อระหว่างหน้า

## 4. คุณสมบัติและเทคนิค

- **Pure HTML5 และ Pure CSS3:** ไม่มี JavaScript, Framework หรือ Library สำหรับส่วนติดต่อผู้ใช้
- **Native HTML5 Validation:** ใช้คุณสมบัติของฟอร์ม เช่น `required`, `pattern`, `type="email"`, `type="number"`, `min` และ `max` ให้เบราว์เซอร์ตรวจสอบข้อมูลเบื้องต้น
- **การนำทางฟอร์ม:** ปุ่มถัดไปใช้ `action` ของฟอร์ม ส่วนปุ่มย้อนกลับใช้ลิงก์ `<a>` เพื่อเปลี่ยนหน้า
- **`formaction` และ `formnovalidate`:** เป็นคุณสมบัติมาตรฐานของ HTML ที่สามารถใช้กับปุ่มส่งฟอร์ม เพื่อกำหนดปลายทางเฉพาะปุ่มหรือข้ามการตรวจสอบเมื่อย้อนกลับได้ อย่างไรก็ตาม หน้าในโปรเจกต์ปัจจุบันยังไม่ได้ใช้คุณสมบัตินี้
- **ชุดสีหลัก:** ส้ม `#e65100` และน้ำเงินเข้ม `#1a252f` พร้อมพื้นหลังสีเทาอ่อนและกล่องเนื้อหาสีขาว
- **รูปแบบการจัดหน้า:** ใช้ CSS Grid, Flexbox และ container แบบกำหนดความกว้างยืดหยุ่น
- **ฟอนต์:** ใช้ Prompt จาก Google Fonts พร้อม `sans-serif` เป็นฟอนต์สำรอง โดยต้องเชื่อมต่ออินเทอร์เน็ตเพื่อโหลดฟอนต์จาก Google Fonts

**หมายเหตุด้านการแสดงผล:** CSS ปัจจุบันใช้ความกว้างแบบยืดหยุ่น แต่ยังไม่มี media query เฉพาะสำหรับการจัดหน้าใหม่บนจอมือถือ อาจต้องปรับ CSS เพิ่มหากต้องการรูปแบบ mobile ที่แยกคอลัมน์ชัดเจน
